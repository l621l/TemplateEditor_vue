# TemplateEditor — использование

1. Откройте адрес фронтенда в браузере.
2. Выберите эфир, затем XML-шаблон.
3. Выберите графику из списка или нажмите «Загрузить». Для анимации загрузите ZIP с PNG-кадрами без подпапок либо выберите несколько PNG.
4. Перетащите графику мышью или введите координаты X и Y, подтвердив их Enter. Для картинки задайте длительность в секундах; для анимации она рассчитывается по кадрам.
5. Нажмите «Сохранить», чтобы записать изменения в выбранный XML.

## Эфиры и шаблоны

Список эфиров берётся из `preferences.xml`. `preset caption` задаёт название, `folder` — папку XML, `id` — номер эфира. Используйте последовательные ID: 0, 1, 2 и далее.

Путь `template file` указывает на XML: `{channel}` заменяется значением `preset channel`, `{preset}` — значением `preset folder`. 
Все пути к файлам должны быть абсолютными. После изменения `preferences.xml` перезапустите бэкенд и обновите страницу.

## Старые файлы

При выборе эфира обновляется дата модификации PNG и ZIP, упомянутых во всех XML его папки. Остальные PNG/ZIP из папки графики, не изменявшиеся более 90 дней, переносятся в `old_png`.

У каждого эфира должна быть своя отдельная папка графики без подпапок. Архив плоский: к имени добавляются название эфира и прежняя дата модификации, при совпадении - номер.
Ошибки архивации записываются в лог и отдельно в интерфейсе не показываются.

## Если что-то не работает

- Нет связи с API: проверьте `apiBaseUrl` в `config.json`, запуск бэкенда и `frontend_origin` в `settings.xml`.
- Не найдена картинка: проверьте `animation folder` в XML и наличие файла. `path_to_pictures` не заменяет этот путь.
- Ошибка сервера: смотрите консоль и папку `Logs` рядом с приложением.
